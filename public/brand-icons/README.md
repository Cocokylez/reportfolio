# Brand icon sources

These assets are stored locally so the portfolio does not depend on a third-party icon service at runtime.

- Google Antigravity: official Google Antigravity press asset.
- ChatGPT and Codex: official OpenAI blossom from `developers.openai.com`.
- VS Code, Claude, TypeScript, Next.js, Tailwind CSS, Supabase, Microsoft Teams, and Microsoft OneDrive: SVG Logos collection, retrieved through Iconify.
- Cursor and Resend: Simple Icons collection, retrieved through Iconify.
- Microsoft Word, Excel, PowerPoint, Outlook, OneNote, and Access: selfh.st/icons collection, retrieved through Iconify.
